# TCC — Avaliação de Arquiteturas para Recuperação da Informação

Este repositório contém os scripts, configurações, documentos
metodológicos e resultados do experimento do TCC.

## Objeto de estudo

Avaliação comparativa de configurações estruturadas, vetoriais,
enriquecidas e híbridas para recuperação de informação - para agentes ou chatbots - em bases
documentais longas e semiestruturadas.

## Ambiente

- Kiro IDE;
- Python 3.13.7;
- DuckDB;
- Git;
- AWS nas etapas finais.

## Situação atual

Preparação do microexperimento local.
